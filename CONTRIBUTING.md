The following is a set of guidelines for contributing to this project.
These are mostly guidelines, not rules. Use your best judgment, and feel free to
propose changes to this document in a pull request.

## How Can I Contribute?

### Reporting Bugs

- Open a GitHub Issue and clearly describe:
  - What you expected to happen
  - What actually happened
  - Steps to reproduce the problem
  - Your environment (OS, Node.js version, etc.)

### Suggesting Enhancements

- Open an issue and describe:
  - The use case you want to support
  - How the change would benefit users
  - Possible implementation approach (if you have one)

### Pull Requests

- Fork the repository and create your branch from `main`.
- Make your changes with clear, descriptive commit messages.
- If you added functionality, add or update tests.
- Ensure CI passes (`npm test` / GitHub Actions).
- Open a pull request against `main` and fill out the PR template.
