# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in this project, please report it responsibly:

- **Do not** open a public GitHub issue for the vulnerability.
- Instead, send a detailed report to [TODO: 你的安全邮箱，例如 security@example.com].
- Please include:
  - A description of the vulnerability
  - Steps to reproduce
  - Possible impact
  - Any suggested mitigations

I will acknowledge your report within 3 business days and aim to provide a more detailed response within 30 days.

## Supported Versions

This project is in early development. Only the latest version is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Security Best Practices

When using this project:

- Do not commit secrets, API keys, or credentials into the repository.
- Use environment variables or secret managers for sensitive configuration.
- Review code changes carefully, especially when running external code or commands.
- Keep dependencies up to date to avoid known vulnerabilities.
